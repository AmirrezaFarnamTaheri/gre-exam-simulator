## 2. Issues Found During AFTER Audit & Resolved

1. **Unscoped global `button` hover override (`globals.css`)**: Bare `button:hover:not(:disabled)` had higher specificity than ETS exam utility classes. Scoped button styling to `.button, .btn-accent, .btn-ghost, .btn-secondary, .tab-btn` with `:where(button)` baseline reset.
2. **8 primary buttons missing `.button` class (`AwaSession.tsx`, `VocabSession.tsx`)**: Caught during live Playwright `/awa` click-through; restored explicit `className="button"` on all 8 actions.
3. **Low-contrast green badge (`ExamResults.tsx`, `FullMockSession.tsx`)**: Replaced `#10b981` + white text (`~2.5:1`) with verified `#166534` / `.btn-accent` tokens (`>= 6.6:1`).
4. **Dark-mode text bleed inside ETS calculator & DI table headers (`GRECalculator.tsx`, `ReviewModal.tsx`, `DataInterpretationQuestionView.tsx`)**: Added explicit dark-ink overrides (`text-gray-900` / `#0f172a`) on light ETS exam widgets.
5. **Missing favicon 404**: Added `web/app/icon.svg` so live browser requests return zero 404 console errors.
